# CarCheck OTG — فاحص السيارة الاحترافي (USB OTG + Bluetooth + Smart AI)

تطبيق أندرويد متكامل لفحص وتشخيص السيارات عبر منفذ **OBD-II** باستخدام كابل **USB OTG** أو محولات **البلوتوث (Classic SPP + BLE 4.0)**، مع واجهة عصرية باللغتين العربية والإنجليزية.

## أبرز المميزات
* **دعم مزدوج للاتصال:**
  * **USB OTG السلكي:** يدعم شرائح FTDI، CH340/CH341، CP210x، PL2303، وCDC-ACM.
  * **البلوتوث المزدوج (Classic SPP + BLE 4.0+):** يدعم قطع ELM327، Vgate، Veepeak، وملحقات الـ BLE القياسية (`FFF0` / `FFE0` / `18F0` / Nordic UART).
  * **وضع المحاكاة التفاعلي:** 3 سيناريوهات جاهزة لاختبار كافة الشاشات دون الحاجة لسيارة.
* **خريطة السيارة التفاعلية (3D X-Ray):**
  * مجسم ثلاثي الأبعاد تفاعلي يتغير شكله تلقائياً حسب نوع السيارة المكتشف من رقم الشاصي `VIN` (سيدان، SUV، بيك أب، هاتشباك، كوبيه).
  * يعرض اسم المركبة أسفل الخريطة ومناطق الأعطال والأجزاء السليمة بالألوان.
* **مؤشرات Cockpit دائرية + تقييم القراءات:**
  * عدادات للسرعة وحرارة التبريد ودورات المحرك وجهد البطارية مع تقييم فوري لكل قراءة (**ممتاز / جيد / مقبول / سيئ**).
* **مسح الأعطال وإطفاء لمبة المكينة (Check Engine Reset):**
  * زر واضح لإرسال أمر OBD-II Mode `04` وأمر UDS `14 FF FF FF` لإلغاء الأكواد المخزنة وإطفاء لمبة Check Engine بعد إصلاح العطل مع إعادة الفحص للتحقق.
* **الذكاء الاصطناعي المدمج (يعمل تلقائياً أوفلاين):**
  * ربط الأعطال للوصول إلى السبب الجذري، خطة إصلاح مرتبة من الأسهل والأقل تكلفة، ومحادثة ذكية تفاعلية (مع خيار إضافي لاستخدام Gemini API).
* **سجلات الفحص السابقة والتحقق من التحديثات:**
  * حفظ التقارير مع تاريخ الفحص واسم السيارة، فتحها أو حذفها بالضغط المطول، تصدير PDF/نص، وزر مدمج للتحقق من التحديثات عبر GitHub Releases.
